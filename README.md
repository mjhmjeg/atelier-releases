# Atelier — downloads

**Atelier** is a native macOS desktop app for [Penpot](https://penpot.app), the open-source design tool. It works with Penpot Cloud and self-hosted Penpot, and supports several accounts side by side.

**[Download the latest version](https://github.com/mjhmjeg/atelier-releases/releases/latest)**: open the `.dmg` and drag Atelier to Applications. Requires macOS 14 or later, on Apple Silicon or Intel.

Once installed, Atelier updates itself from this page.
